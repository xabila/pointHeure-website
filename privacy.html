PointHeure

Politique de Confidentialité

Dernière mise à jour : 30 janvier 2026

Résumé : PointHeure respecte votre vie privée. Toutes vos données restent sur votre appareil. Nous ne collectons, stockons ou partageons aucune donnée personnelle.

1. Introduction

PointHeure ("nous", "notre", "l'application") est une application de suivi d'heures de travail conçue avec le respect de votre vie privée comme priorité absolue.

Cette politique de confidentialité explique comment nous traitons (ou plutôt, ne traitons pas) vos informations lorsque vous utilisez notre application.

2. Données collectées

Nous ne collectons aucune donnée personnelle.

PointHeure fonctionne entièrement hors ligne et stocke toutes les informations localement sur votre iPhone :

  • Vos heures de pointage
  • Vos paramètres (objectif hebdomadaire, jours travaillés)
  • Vos projets et lieux de travail

Ces données ne quittent jamais votre appareil et ne sont transmises à aucun serveur.

3. Stockage des données

Toutes vos données sont stockées localement sur votre iPhone via le framework SwiftData d'Apple. Elles sont :

  • Protégées par le chiffrement natif d'iOS
  • Accessibles uniquement par l'application PointHeure
  • Sauvegardées dans vos sauvegardes iCloud (si activées)
  • Supprimées automatiquement si vous désinstallez l'application

4. Partage des données

Nous ne partageons aucune donnée avec des tiers.

Puisque nous ne collectons aucune donnée, nous n'avons rien à partager. Aucun analytics, aucun tracking, aucune publicité.

5. Services tiers

PointHeure n'utilise aucun service tiers susceptible de collecter des données :

  • Pas de Google Analytics
  • Pas de Facebook SDK
  • Pas de Firebase
  • Pas de publicités

6. Localisation (optionnel)

Si vous activez la fonction optionnelle de pointage automatique par localisation :

  • Votre position est utilisée uniquement pour détecter votre arrivée/départ du lieu de travail
  • Ces données restent sur votre appareil
  • Aucune position n'est transmise à nos serveurs (nous n'en avons pas)
  • Vous pouvez désactiver cette fonction à tout moment

7. Sécurité

Nous appliquons les meilleures pratiques de sécurité :

  • Architecture "privacy by design"
  • Aucun serveur = aucun risque de fuite de données
  • Chiffrement iOS natif
  • Code source auditable

8. Droits RGPD

Conformément au Règlement Général sur la Protection des Données (RGPD), vous avez les droits suivants :

  • Accès : Toutes vos données sont visibles dans l'application
  • Rectification : Vous pouvez modifier n'importe quelle entrée
  • Suppression : Désinstallez l'app pour supprimer toutes les données
  • Portabilité : Export disponible dans les paramètres

Puisque nous ne stockons aucune donnée sur nos serveurs, l'exercice de ces droits est immédiat et sous votre contrôle total.

9. Enfants

PointHeure n'est pas destinée aux enfants de moins de 16 ans. L'application ne collecte aucune donnée, y compris de mineurs.

10. Modifications

Nous pouvons mettre à jour cette politique de confidentialité. En cas de changement important, nous vous en informerons via l'application.
